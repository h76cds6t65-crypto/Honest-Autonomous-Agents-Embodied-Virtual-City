# 自成之境 v2.35 開發基線與驗收交接

2026 年 11 月 8 日 · [English](README_EN.md) · [公開現況](../../CURRENT_STATUS.md) · [v2.34 驗收規格](../v2.34/README_ZH-TW.md)

自成之境研究自主數位居民及其具身世界。v2.35 依 v2.34 的順序完成一房間提交、恢復與模擬日的本機隔離驗收，再驗原版 65 維身體方程的短時單次碰撞及去重。居民的身份、私域、拒絕權及有來源的記憶繼續依既有規範。驗收指標用於工程核對，正式居民的開發與部署依 P-02 另行批准。

## 一房間提交與觀察

解析場景使用一個固定形態研究替身、120 tick/s 和單機 SQLite。第 120 tick 發生一次碰撞，替身與牆支座分別承接 −20 和 +20 N·s，接觸耗散 10 J。版本、回執及指定觀察來源在同一交易持久化。觀察投影獨立保存其來源及寫入時間。

| 驗收 | 實跑結果 | 檢查 |
| --- | --- | --- |
| W34-01 單次碰撞 | 一筆世界效果、一筆原回執和一筆有來源的合成觀察。 | 15/15 |
| W34-02 重送與併發 | 依序重送、8 個程序同時提交及重送與投影併發，效果與觀察各只計一次。 | 48/48 |
| W34-03 同 ID 內容衝突 | 改變 tick、恢復係數或讀取版本的同 ID 請求遭拒。原回執及帳可回查。 | 18/18 |
| W34-04 持久提交前中斷 | 終止程序後重開，未提交的碰撞、回執及來源皆無。查證後重送一次生效。 | 16/16 |
| W34-05 已提交但回執未送出 | 呼叫端保留 `IN_DOUBT`。重開查回原回執，重送回應逐位元相同。 | 12/12 |
| W34-06 已提交但觀察未投影 | 重開找到待投影來源。補寫一次，反覆重開不新增觀察。 | 16/16 |
| W34-07 世界有碰撞且無目擊 | 有回執及世界效果。觀察來源與第一人稱記憶均為零。 | 14/14 |

以上各項為 `PASS_WITH_SCOPE`。檢查數是各項主驗收，回歸與對照各自保存。

## 原版 65 維的短時碰撞

| 驗收 | 狀態與範圍 |
| --- | --- |
| C32-03 單次碰撞 | `PASS_WITH_SCOPE`。封存的 v2.14 方程及 v2.11 依賴在一個 S 型靜息代理上積分 6 秒。獨立 WORLD 回執於 tick 121 觸發一次跳躍，接觸損失約 0.00746667 J。最終 37/37 項通過。 |
| C32-08 同事件去重 | `PASS_WITH_SCOPE`。單次、依序重送及四寫入者競爭三組各只應用一次。各 722 筆完整 65 維軌跡與 C32-03 封存的 BDF 外掛阻尼熱分支逐位元一致。正常重開可取回原回執。32/32 項通過。 |

C32-03 首次直接積分絕對世界化學能庫存時，24/36 項通過，整體為 `FAIL`。後續使用相對初值的增量座標，呼叫原方程時還原絕對庫存，沿用初值、原方程與驗收門檻。純原方程碰撞後約 0.0003023 J 的阻尼熱缺口列 `FAIL_EXPECTED`。另以外掛將關節阻尼功率入核心熱代理，BDF 全窗最大能量殘差約 3.54×10⁻⁶ J。兩條碰撞路徑及失敗診斷各有證據。

## 待執行的驗收

C32-04、05、06 依序追蹤碰撞後 1、24、72 小時的關節熱帳、氧與 ATP、守恆及數值穩定性。C32-09、10 檢查原版 65 維身體端在提交前及提交後回執送出前的真實程序中斷。上述各項均為 `NOT_RUN`。C32-01、02 是早期的無碰撞靜息基線。熱保護 ATP、氧輸送與 24 DPB 整理各依 v2.34 所列的候選證據。GitHub 託管 CI 為候選。

下一輪建議以 C32-04 的一小時配對接續。材料、器官、形態變更、跨主機權威及自主生活仍各有驗收範圍。
