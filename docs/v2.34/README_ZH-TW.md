# 自成之境 v2.34 開發基線與驗收規格

2026 年 11 月 8 日 · [English](README_EN.md) · [目前狀態](../../CURRENT_STATUS.md) · [v2.09 離線研究](../v2.09/README_ZH-TW.md)

自成之境研究自主數位居民及其具身世界。居民的自主生活、拒絕權和記憶私域屬於設計原則。世界事件和居民觀察各有來源，測試分數只用於檢查工程條件。R-001 至 R-170 與 P-02 依原效力適用。接續工作限於隔離研究，正式居民程式與部署依 P-02 另行決定。

## 開發順序

先在一個房間用固定形態的合成替身，驗收碰撞的持久提交、重送與中斷恢復。再沿用同一場景跑完一個模擬日。原版 65D 身體模型的單次碰撞及去重以 C32-03、08 另行驗收。翼尾、材料、器官及更長時間的生理研究依各自的證據接續。

| 項目 | 最小通過條件 | 本版狀態 |
| --- | --- | --- |
| W34-01 至 07 單次碰撞與恢復 | 正常提交只產生一次物理效果與一筆有來源的觀察。同 ID 同內容重送取得原回執。內容衝突不改變世界。提交前後中斷與投影延遲均可對帳。未觀察到的事件沒有第一人稱記憶。 | 候選規格 · NOT_RUN |
| W34-08 至 10 一個模擬日 | 世界累計 86,400 秒模擬時間。停機的牆鐘留痕另存。無中斷與恢復版的最後物理狀態、碰撞次數、帳目和觀察對得上。 | 候選規格 · NOT_RUN |
| C32-03 原版 65D 單次碰撞 | 固定原碼、初值、環境和容差。精確分段，比對無碰撞軌跡，查原慣量、局部衝量與收支。 | NOT_RUN |
| C32-08 原版 65D 去重 | 用同一原版適配器重送。比對物理軌跡、事件回執與效果計數，確認跳躍只施加一次。 | NOT_RUN |

### 一房間的候選夾具

候選刻度為 120 tick/s。20 kg 單軸替身從 x＝0 以 1 m/s 朝正向平面移動。第 120 tick 在 x＝1 m 發生恢復係數為 0 的接觸，速度變為 0。候選帳目為替身衝量 −20 N·s、固定牆及支座 ＋20 N·s、接觸耗散 10 J。之後維持靜止。這組值只用於解析替身。模擬日的終止刻度是 10,368,000 tick。

權威提交把世界版本、事件回執和待投影的觀察來源一同持久化。操作鍵以世界分支與操作 ID 定位，雜湊對應規格化內容。相同內容的重送依回執查詢權限取回原結果。操作結果未明時保持 `IN_DOUBT`，待查到權威提交才判定。記憶投影保留來源操作、世界版本和觀察 tick。停機期間只留下可核實的系統紀錄。若崩潰的時刻只能確定在某個範圍，保留時間區間。

## 後續的身體與世界研究

四位居民各有 Q、S、M 設計形態。原始 65D 涵蓋九個參數身體，十二形態需各自驗證。以 S 形態作候選基準，Q、M 重新估計質量、慣量和散熱。外觀、碰撞及解剖代理分開。翼和魚尾使用各自的材料、受力和失效條件。強化還需核對肌肉做功、供氧、ATP 和熱。實體變形與外觀切換仍是待決設計，結構質能場與掃掠碰撞按各自前提研究。

多尺度聯立、有限結構場、跨主機一致性和自主學習與社會整合仍依原研究線追蹤。讀取版本、場景、輸入、環境、回執與原始輸出共同界定驗收結果。遇到未跑、缺件和部分通過時，各自保留狀態。
