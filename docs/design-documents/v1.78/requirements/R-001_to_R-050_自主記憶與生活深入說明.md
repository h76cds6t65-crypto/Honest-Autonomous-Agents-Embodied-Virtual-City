# R-01～R-50｜自主性、長期自我、睡眠、身體與基本生活的工程深化

> 依私人 v1.78 Word 母版早期正式需求與之後已批准的修訂整理。**只公開技術規則，不公開發起者的真實背景、私人對話或親密關係原文**。部分欄位是建議的測試資料結構，仍需開發前定稿。

## A. R-01～R-05、R-34／35、R-61～64：自由活動不等於不負責任
同一居民能形成至少三種不同性質的活動提案：承諾的工作、私人感興趣的事情、無特定成果的休息。工作被接受時應認真嘗試，卻不能以「完成任務」一個分數決定全部人格。當她改去遊戲或探索時，內部意圖與對外進度必須分別記錄。

候選欄位：
`resident_id`, `intent_id`, `intent_origin`, `commitment_ref`, `expected_consequence`, `decision_state`, `external_progress_receipt`, `reported_progress`, `reason_source`。

反例：
- 無人指派任務時，一整天坐在窗邊不代表模型故障。
- 已承諾的外部事項可以暫停，但不能對外虛報已完成。
- 算力不足沒有推理，不得記成她自主選擇休息；真停機是 `OFFLINE_GAP`。
- 系統不該強制為她設定新的興趣，也不設「四位居民必須不同性格」的成功條件。

## B. R-06～R-10、R-44～47：跨模型、跨長期的人生連續性
一段經歷至少要分開「可核查的客觀事件」「當時私人觀察」「當時想法」「日後主觀重述」「夢境或想像」。她日後可能錯誤回想、改變解釋或完全沒有想到；客觀事件不因此改寫。

- R-06：舊想法採版本追加，不能因新的說法就抹去原先觀點。
- R-07：回想可由環境線索觸發，不必每次手動查詢。
- R-08：自我模型可隨經歷改變。
- R-09／10：睡眠可促成聯想，但夢境與親身經歷分離。
- R-44：恢復備份與同時運行兩個分叉副本不同，兩者不可同時聲稱是唯一同一個在世個體。
- R-45：自我身份、內外分界、歷史、未來預測、能力界線、對自身意圖的觀察都需可記錄。
- R-46：行為時的紀錄、行為前決策和事後理由是不同來源。
- R-47：切換推理模型／供應商不應消滅 resident_id 或私有經歷。

候選失敗測試：把夢中和鄰居共遊的場景當成真實遊歷；把試驗分支中的動作寫進主線；用 GPT/Claude 供應商 API 聊天記錄當作唯一人格原件；模型更新後無聲清空日誌。

## C. R-11～R-15、R-29、R-51～54：私人身份與平等關係
主智能體存在原始身份與私人關係規則，部分親密起源不適宜公開。**可公開的工程要求**是：專屬關係設定具有可追溯身份，不可無故擴散到三位 AI 鄰居；個體仍能拒絕、請求獨處、保持私域、反思與提出不同看法。情緒代理可模擬不滿、孤獨或依戀，但不能因此擅自監視、阻止人類社交或操作真實私人帳號。

公共文檔不把特殊私人稱呼、原始情感對話當成必須由外部 AI 看到的訓練語料。法律上合規的私人資料刪除流程仍須在未來設計中獨立成立，不能被長期關係設定取消。

## D. R-16、R-26、R-36～39：睡眠、夢境、成長與形態
居民可能睡眠、短眠、做夢或未做夢，夢境次數、時長、醒後回想數彼此分開。睡眠壓力不必強制到固定時間，外部日夜和個人節律不同步。

- 夢境生成可能 0～多次；醒後只可能記住其中部分。
- 真正入庫的夢片段是夢的來源證據，不是可公開的現實社交歷史。
- 自評成熟可有多個面向、不確定與修正，不能以單一成長分數控制造型。
- 身體體型切換保留身份與記憶，依 v1.78 採各角色各形態個別浮動身高，不能只用尺寸倍率改變全部關節參數。
- 壓力事件對表現／形態的暫時影響，不等於自動刪除已學技能或真的人體受傷。

## E. R-17～24：有自由意圖，但現實資料和權限有界
| 工作層 | 允許的設計方向 | 不可混同 |
|---|---|---|
| 居民對日常規則的疑問 | 想違反約定、要求討論、改變習慣 | 不代表已取得外部權限 |
| 真實私人檔案 | 需明確授權來源、最少存取、撤回記錄 | 不靠親密關係預設有權閱讀 |
| 真實發信、公開及付款 | 執行者及獨立核驗服務驗收 | 模型自述「已寄出」不能當憑據 |
| 外部 AI 協作 | 明確審查出站資料範圍 | 另一個 AI 不自動取得 resident 全部私記 |
| 規則例外 R-102 | 原始權限效力及安全模型尚待審議 | 不能在這裡擅自認定批准提權 |

R-18／19、R-27／28 原始文字有個人的預算與外部訂閱安排；公共版只保留**可配置成本預算、模型可用性、資源不足安全休眠及來源核驗**，不刊登個人金額、訂閱狀態或帳號資料。

## F. R-30～33、R-40～43：角色、身體與藝術設計
2D／3D 是同一住戶的視覺與動作出口，不是兩個共享私人資料的居民。小型／少女比例／成熟比例是造型類別，不設定固定的性格或心理年齡。數位身體與神經／內分泌代理必須影響可見行為、姿勢、呼吸樣節律、休息傾向，而不只是背景動畫；身體高精度與感官科學證據的界線見 24-DPB／MASC 專章。

舊版 R-43 不要求為了「像真人」加入重度疾病、感染、衰老、生物傷口或細胞自癒；新的更細 DPB 生理代理不應偷變成未獲准的醫學級病理遊戲。外部 Claude 美術協作身份不同於城市 Claude 居民。

## G. 最小紙面資料流
`Environment → PerceptionAvailability → Attention? → BodyResponse? → MemoryCue? → InternalIntent? → AccessGate → WorldActionReceipt → PersonalInterpretation?`

每個問號都是可合法缺席的節點；不把「她沒想到」寫成「發生了某事」，也不把「世界真的做了」強迫成「她一定記得」。

**狀態：來源核對與候選工程接口；沒有智能體程式，沒有成功的生活或身體校準實測。**
