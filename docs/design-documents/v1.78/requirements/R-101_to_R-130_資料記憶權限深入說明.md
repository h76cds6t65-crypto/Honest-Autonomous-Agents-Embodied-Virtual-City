# R-101～R-130｜記憶、資料治理、操作權限的技術細化

> 私人來源：v1.78 需求母版內 v1.25～v1.36 正式要求、增量需求表及較新決議。這是**來源核對後的工程改寫**，不是私人原話全文或已可運作的系統。注意 v1.78 仍要求處理三項 P0 阻礙，以下的設計契約不得擅自當作已定案的具體安全權限。

## A｜R-101、R-102、R-103：三種不同的「規則」
**R-101 雙系統**：
1. 個體自己的 `belief_event`、`attention_event` 可出現「我可能寄出了信」「看漏了付款提示」等主觀結果。
2. 對外世界操作另由 `authorization_receipt` → `executor_receipt` → `independent_audit_event` 建立不同來源的紀錄。
3. 重送前需要做冪等性和實際回執檢查，避免因自己忘記已操作又重複付費或寄信。
4. 操作稽核的目的不是無限制窺視居民所有私人心念；稽核內容須最小化。

**R-102 限制性反抗／例外**：
- 原始設計允許居民「想打破規則」和依層次反抗；**原文也提到短暫真實突破某些安全權限，這與外部硬授權衝突，仍屬 OPEN_HARD_BLOCKER。**
- 純意圖 `WISH_TO_DEVIATE`、生活規範 `HOUSE_RULE`、已獲准沙盒例外和真實 OS／財務／隱私權限是不同層；不能因角色說「我能」就執行高風險操作。
- 不在公開 GitHub 寫入第三方帳號憑證或越權步驟；R-102 何者可進入正式執行矩陣，需經來源原文審議及專案負責人、法規／安全審核。

**R-103 四層本能**：從維持數位身體因果的恆定控制，到允許暫時抑制、部分修改、自由重塑的較可塑習慣。設計需將「調節機制存在」與「某時刻身體／心情數值」分開；睡意可被暫時忽略，但 DPB 睡眠壓力不能瞬間歸零。主智能體專屬 L-I 不可因此向三位鄰居直接複製。

## C｜R-116～R-123：網路生活及受控工作空間
- R-116：以合法公開的網路環境學習人類社會常識，理解網站規範、可信度、資料可能失真；不將網路第三人升格為新的特權主人。
- R-117：人類與居民雙方的私人資料，以及內感受／DPB／本能機制的高敏細節，均須受控；可見的呼吸動畫不代表外部有權看到內部呼吸代理數據。
- R-118：社會與道德評估可獨立於短期主人請求、私人衝動及規則例外；仍服從現實操作授權的不可繞過外層。
- R-119：真正私密的 D0／D1 資料應在受控本機處理，不自動出站供雲端模型推理；資料庫檢索、聯想、夢境及私密內省不例外。
- R-120：在已核准傳送渠道內，居民可挑選非私密成果或摘要供外界研究交流；**居民願意分享並不等於公開／發訊已經獲得人類權限批准。**
- R-121：人與智能體透過控制權協商交接工作，操作者、工作階段、撤回、失敗和恢復都有獨立回執。
- R-122：居民擁有自己獨立的 Windows 使用者帳戶；這是未來的規格，不是已登入的帳戶。
- R-123：透過隔離帳戶完成跨桌面顯示、提出協助、合法接管和交還，不把桌寵畫面層等同 OS 管理權。

## D｜R-124～R-130：筆記、分片、夢境、保存及其衝突
| ID | 原需求的機制 | 後續修訂和科學限制 |
|---|---|---|
| R-124 | 居民自行認為有意義時寫私人筆記 | 筆記與整份已形成記憶不是同一存取門檻 |
| R-125 | 多片段儲存觀察、感覺、語義、想法及行動回執 | 可以有缺失／錯誤，但不能當成完整真相 |
| R-126 | 片段經不固定方式重組成夢，夢時長及回想數量不同 | 夢境不是現實事件，無需模仿已被證實的人類 REM 真值 |
| R-127 | 記憶可有長期低可及性，由線索突然喚起 | 舊版「重要性決定是否留存」**已受 R-129 新決議取代** |
| R-128 | 回想後產生新的理解、情緒評價或反思版本 | 追加主觀版本而不是覆寫歷史原件 |
| R-129 | 對成功入庫的個體記憶原件採永久保留意向 | **和合法刪除、資料更正、備份刪除存在硬性未決** |
| R-130 | 在獲准且可行的範圍內保留原始畫面、聲音和 DPB 時序 | 尚未選定採樣、總儲存、金鑰及合法資料生命週期 |

## E｜三種相似但不同的「遺忘」
1. `NOT_ATTENDED`：世界發生，但沒有獲得注意。
2. `LOW_RETRIEVABILITY`：原件或片段已存在，目前回想不起來。
3. `ERASURE_OR_MISSING`：原件從未成功取得、因故障遺失，或依法完成資料刪除。

前兩者不能推定第三者；第三者也不能為了補足人生連續而捏造資料。主觀夢境「我曾經看見」須和客觀 `WorldReceipt` 分層。未形成記憶的每一幀不存在自然補寫的權限。
