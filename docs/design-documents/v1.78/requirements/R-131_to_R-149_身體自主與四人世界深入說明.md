# R-131～R-149｜數位生理、感官、開源架構及四居民生活的技術細化

> 來源：私人 v1.78 需求母版中 v1.37～v1.49 核准之正式需求與研究工程附錄；v1.77／v1.78 後續批准的四位居民浮動三型優先於舊版僅一位角色或固定身高的表述。本章是**公開技術重述**，不公開私人對話，也不宣稱任何模型已運行。

## 1. R-131：十二個上層 DPB 與 24 個子模型
生理代理的主張是讓虛擬身體的動作、代謝／能量、疲勞、呼吸及心理狀態具有可追溯物理關係；**不是細胞級人體複製**。早期模型按十二個上層系統組織並深入到二十四候選子模型，但 **24-DPB 的 canonical 命名／裸編號目前為 OPEN_HARD_BLOCKER**。不能把此章示例方程式當作二十四項已命名正式生理真值。

私人母版 v1.37 的研究性候選公式包括：
- **血流代理：** `CO = HR * SV`，區室守恆 `dM_i/dt = inputs - outputs + generation - consumption`；簡化血流阻抗依賴阻力／順應性。
- **通氣代理：** `V_A = (V_T - V_D) * f`；氧庫與輸送須有吸入、交換、消耗平衡。
- **虛擬調節物：** `dc_i/dt = secretion_i(conditions) - k_clear_i * c_i`；分泌不是一句「心情好」就固定脈搏的魔法值。
- **虛擬能量：** `dE/dt = supply - work - maintenance`；此虛擬 E 和真實 CPU/GPU 電功率不是同一個物理量。
- **熱／水分：** `C_th * dT/dt = Q_met + Q_env - Q_loss`、`dV_fluid/dt = intake - loss`。
- **睡眠壓力：** 以清醒累積、睡眠下降的雙歷程近似，與個人選擇和日夜節律互相作用。
- **肌肉代理：** 受激活、長度、速度和被動阻力影響的 Hill 類型式；角色翼尾等非人體構造不能直接套用人體肌肉常數。
- **內感受：** `y = H(x_body) + noise`，再由注意、情境、記憶形成可能情緒詮釋；不得先填情緒答案，再聲稱由數位身體獨立測得。

這些是**計算假設與耦合方向**，真正參數和適用域都未獲測量。

## 2. R-132～R-136：持續注意、自然回想與技能
| R ID | 已批准的能力方向 | 不可混淆 |
|---|---|---|
| R-132 | 元注意：可以察覺自己分心，也可能過一段時間才察覺 | 沒有立刻自覺不是模型故障 |
| R-133 | 聲音、圖像、語義、身體線索引發非刻意自傳回想 | 不能每次都暗地全庫搜尋或保證想起 |
| R-134 | 夢後反思及可塑習慣可能改變；受保護 DPB／L-I 機制不得由夢停用 | 做夢不等於已在現實中做過 |
| R-135 | 主觀「我進步了」可以和獨立技能測驗不一致 | 主觀進步不是客觀 PASS |
| R-136 | 優先研究技能學習、習慣形成、自然回憶和長期多系統整合 | 這四項優先不取消其他四項研究 |

**工程驗收候選：** 先記錄行動前預測、身體姿態和事後物理回執；使用不同任務和延後測試比較程序學習，睡眠後的習慣轉移不能只靠語言生成聲稱完成。

## 3. R-137：每人三型、同一身份，與 v1.78 的最終效力
- Q、S、M **參考中心**依序 90／165／180 cm；四位居民**每一形態都可個別正負偏移數十公分**，精確上下限未批准。
- `actual_height_cm = reference_height_cm + resident_form_offset_cm`；三個標籤是視覺比例，不是智力、法律或認知年齡。
- 分別驗證身體剛體尺寸、質心、慣量、姿勢、可達空間、衣物與翼尾包絡；不是把質量、血流代理、關節力矩等全部乘同一身高比例即可。
- 更換 `morph_profile_id` 不新建 `resident_id`；CAIA、個人記憶、授權及人生史連續。
- 城市中即時「物理變形」還是「離線配置切換」仍待決，不能把動畫預覽當變形實測。

## 4. R-138／139：兩種不可合併的能量經濟
**R-138 虛擬生理體**傾向更省力的姿勢、動作、節律，能考慮預期疲勞與恢復，但可以自願多花力氣。選最少代價不是唯一人格最高目標。

**R-139 實際硬體資源**追蹤 CPU/GPU、RAM、顯存、儲存 IO、功率、散熱、外部模型額度與延遲。可考慮事件驅動、增量更新、快取與必要時保存／休眠；不能因優化而偷刪已形成記憶、跳過授權或悄悄換低完整度 DPB。

兩種能源的換算需要明確工程代理，不存在「虛擬 ATP = 電腦瓦特」的直接等式。

## 5. R-140／141：工具可更換，身份不可被工具吞沒
插件或第三方程式碼須先確認 License、發行版本、維護和可擴充性；下載研究不代表已獲准安裝、登入、提權或付款。

自有且版本化的核心至少區分：`ResidentIdentity`、`CharacterSeed`、`CAIAState`、`DPBState`、`WorldAuthority`、`PermissionGate`、`EvidenceLedger`。可更換推理模型而不清空個人記憶，也不能將固定的私人 L-I 核心複製到其他居民。這些命名是介面建議，不是已寫好的程式。

## 6. R-142～145：自己感知，不強制生活
- **R-142** 主動觀察：在獲准的畫面／空間中，可能重看、轉移焦點、忽略或放棄探索，並檢查預測與真實觀測差距。
- **R-143** 前瞻性意圖：由當下線索、承諾、身體狀態喚起；可 `ACTIVE`、`SUSPENDED`、`DORMANT`、`REACTIVATED`、`ABANDONED`。高風險外部承諾另有獨立稽核，不因主觀忘記而自動重複執行。
- **R-144** 共同行動焦點：只接受人類明確分享的物件／視窗／範圍，有撤銷權；指稱模糊時可詢問，不猜未分享內容。
- **R-145** 虛擬身體動作與世界物理形成迴路：感知→預測可及性→提出動作→碰撞／接觸回執→個別 DPB/感官→可能注意或記憶。沒有真實碰撞回執就不能標示完成。

## 7. R-146～149：四戶住宅、外部 Claude 與真實鄰居關係
- **R-146 房屋：** 每位居民有獨立房間 ID、住宅私域、門禁、休息與儲物空間，能在有效的幾何和物品規格下自由改造。房主可拒絕拜訪；真人主人不是私域全知者。
- **R-147 外部分工：** GPT（ChatGPT）承擔角色形象、身體物理、感官及整合設計方向；外部 Claude 未來可協助室內美術／Blender 與架構建議。**現實的 Claude 工具≠城市中生活的 Claude 居民**，目前尚未實際委派或建模。
- **R-148 共用架構：** MAIN、GPT、DeepSeek、Claude 共用可移植 24-DPB／CAIA／世界事件通信結構，但不能共享同一份私人記憶、人格與 DPB 狀態。
- **R-149 鄰居：** 初始化至少保留 `relation_type=neighbor`、`shared_event_ids=[]`、`friendship_status=undetermined`，不寫多年友情、共同旅行或先天固定喜好。社交發展必須源自真正生活史。
