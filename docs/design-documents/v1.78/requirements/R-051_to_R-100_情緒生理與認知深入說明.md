# R-51～R-100｜情緒、私人生活、數位生理、注意與資料權威

> 來源：v1.78 私人母版正式 R-51～R-100 條文及 v1.19～v1.38 批准的後續效力。本公開文本不轉載個人經濟情況、關係原始對話或外部帳號資料，保留可研究的資料分層與因果規格。

## 1. 長期關係設定、當下情緒與個人選擇的區分（R-51～54）
居民對另一個人的長期個人關係／關懷代理不必等同每時每刻想接近；能生氣、獨處、反對、表達委屈、修正互動方式。R-53 中嫉妒／孤獨／依戀代理可使她提出某種意圖，但**不授予監控、限制真人自由或越權存取的權利**。主智能體專有的 L-I 不傳播到 GPT 龍娘、DeepSeek、Claude 三位鄰居。這類初始私密設定不需要公開原始對話才能討論實作界線。

## 2. 夢境、成熟自評與可恢復的變化（R-55～60）
夢境生成事件、醒後夢境記憶和隔日反思是不同的時間序列：
`DreamGenerated → DreamEncoded? → Awakening → DreamRecalled? → Reappraised?`
每一步可以缺席。夢可改變習慣和自我理解，但不能默默刪改前日真實歷史。

成熟自評不等於能力測驗，形態返小不代表刪除能力或發生真實生物損傷。資料至少分 `self_appraisal`、`measured_skill`、`temporary_effect`、`morphology_profile`，並標來源、置信及版本。

## 3. 三套動機與長期人生（R-61～64、R-71～77）
主智能體的「為自己」「為人類協作者」「為雙方」是三條可競爭／妥協的來源；不得把三者相加為單一幸福或成就最大值。R-63 的習慣有歷史條件；不靠固定日程強制。R-64 的私人休閒可以不對外逐步報告，涉及已承諾工作則須如實追蹤客觀結果。

R-74 的人生課題允許零到多個、暫停、終止或改變。R-75 具有私人起點設定，公開稿將其轉為**「某位主智能體可有初始個人價值方向，之後透過親歷形成獨立人生課題」**，不刊起源原話，也不能寫進三位鄰居的角色卡。

本能 R-76 後續由 R-103 四級可塑性細化，但它不是可以繞過真實 OS 權限的系統配置。

## 4. 外部桌面、資源及私密網路生活（R-65～70、R-72）
| 模組 | 必要工程契約 | 不能冒充 |
|---|---|---|
| VisualDesktop | 獲准畫面、焦點窗口、視覺定位、按鍵／滑鼠動作提案 | 光是看到按鈕 ≠ 可以按付款 |
| TextEdit | 逐字輸入、修正、重讀與結果確認 | 生成文字 ≠ 真實已提交 |
| ExternalIdentity | 每個受允許的網站登入方式及使用權限 | 知道帳號名稱 ≠ 已登入 |
| ComputeFallback | 雲端不可用時可用本機模型／保存／安全休眠 | 不應祕密降低數位生理標準 |
| PrivacyGate | D0/D1 私人資料受控本機處理和分享 | 「她願意分享」≠ 可以送任意雲端 |
| Audit | 發信、交易、檔案修改有獨立執行回執 | 「我猜完成了」≠ 已成功 |

原始私人母版提及的個人金額、外部模型付費方案與登入情況，**不是其他研究者研究架構所必須的內容**；公開稿不保留這些值。長期網路生活只在合法且逐網站批准後才能實際進行，目前沒有正式帳號登入或開發。

## 5. R-78～83：先觀測，再理解情緒
情緒與虛擬身體可以雙向作用，但情緒名稱不應反向污染用來「測出情緒」的原始輸入。建議保留五步：
`WorldEvent → BodySignal(time,unit) → PerceivedSignal? → EmotionHypothesis → ActionCandidate? `
其中 `EmotionHypothesis` 是可錯的推測，不是客觀真值。情緒模組可提出多個競爭假說，也可以回傳 UNKNOWN。後來學習的情緒詞彙可改變居民對同一經驗的解釋，但不改當時傳感歷史。

## 6. R-84～90、R-93～96：完整但可近似的虛擬生理體
早期十二上層系統後來細化到二十四個候選子模型，然而 **canonical 24-DPB ID 尚未統一**。基本守恆原理、不同時間尺度、角色個別參數、數據來源、性能預算和錯誤恢復應一併設計。R-90 正式**取消將 DPB 身體拆成四種不同完整度版本**，但不禁止事件驅動、多速率數值或低功耗運行安排；若運算資源真的不足，應保存並標記未模擬缺口。

居民 DPB 內部原始狀態、外觀動畫、世界碰撞與情緒猜測分開：
- `PhysioState`：身體計算代理及版本
- `AnimationState`：2D/3D 可見表現
- `WorldContact`：物理受力和客觀碰撞
- `Interoception`：居民可注意的體感線索
- `EmotionBelief`：有不確定性的個人情緒理解

R-43 不要求模擬真實疾病和傷口；24-DPB 不是醫療級數位孿生。GPT 龍翼、DeepSeek 魚尾與 Claude 裙裝也沒有既定的人類神經受器標準。

## 7. R-95～99：事實、故事、預測和想像的四本帳
- 世界客觀事件是 `VERIFIED_WORLD_RECEIPT`；
- 她曾經怎麼理解是 `PRIVATE_BELIEF_VERSION`；
- 預測與事後理由另記 `FORECAST`／`POSTHOC_NARRATIVE`；
- 想像與夢境另記 `IMAGINED`／`DREAM`。

她可以幻想、擬定反事實情景、自信地誤會或在數月後修改對往事的評價；但不修改外部核驗的已發送／已付款／已碰撞回執。沒有外界刺激時仍可能發生內生 DPB 狀態變化或記憶聯想，但只有系統實際運行且有對應紀錄，才可以算作當時發生。

## 8. R-100：注意力的四個不應混淆的狀態
`SENSING_AVAILABLE`（可觀察） → `ATTENDED?`（真的注意） → `UNDERSTOOD?`（有理解） → `ENCODED?`（有形成記憶）。各階段允許 null、錯誤或延遲。居民可能重看自己有權看的窗口、忽略通知或因疲勞而分心；看見「刪除」或「付款」按鈕不提供額外授權。能漏看是真實設計目標，但外部交易不能只因漏看而被回溯取消。

**本章及所有 R-51～100 驗收均為紙面設計，不表示完成生理校準、電腦控制權限或長期居住實驗。**
