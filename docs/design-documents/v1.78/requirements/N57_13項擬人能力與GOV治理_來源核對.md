## 文件治理的五項方向

| ID | 類型 | 預期檔案行為 |
|---|---|---|
| GOV-A | 權威規格總表 | 分開已批准需求、工程候選、已完成驗收與歷史失效決議 |
| GOV-B | 反例 | 重要規則同時給予成功條件、否決反例及必要證據 |
| GOV-C | 證據分層 | 人體實測、物理近似、類比、純角色幻想需獨立標記 |
| GOV-D | 跨模組責任鏈 | 意圖→控制→接觸→感官→認知→記憶的來源可查 |
| GOV-E | 不以規格數字冒充進度 | 將證據與缺口關閉當作工程成果，不以新增編號取代驗證 |

## 不能沿用舊意涵的 N-10

v1.58 已修正：四位居民**可以性格相似、興趣相似甚至完全相同**。N-10 的正確目標是審計共用後端造成的私人資料串用、被動模式塌縮或不必要的強制差異，而**不是**以「四人必須不同」作 KPI。正式自我、記憶、生活史和身體控制仍分離。

本文件只有 13 個可公開重述的能力方向與五個治理方向；歷史曾記錄 N57-T 紙面案例集合，但原始逐筆對應仍須另外核查；**不得假稱已逐筆復原或實測**。與 R-102、記憶合法刪除、24-DPB 正規編號相關者皆未結案。
