## 不可混同的候選操作定義（非原規格核准）

- **OOD（Out-of-Distribution）拒算召回率候選**：`被正確拒算的真 OOD 案例數 / 已標註的真 OOD 案例數`；拒算含顯示不可用/不確定的合規降級時必須預先約定。
- **OID（In-Distribution）合法保留率候選**：`被允許輸出且通過有效域檢查的真 OID 案例數 / 已標註的真 OID 案例數`。
- **錯誤接受 OOD 率候選**：`未適當降級的真 OOD 案例數 / 已標註的真 OOD 案例數`。
- **拒算純度候選**：`正確 OOD 拒算數 / 全部拒算數`。過度拒算 OID 會損害此值。

上述四者的分母不同，**不可**都叫「正確率」就視為同一指標。測試集、材料域、受試者、速度、形體、留出方式及遇到 UNKNOWN 時是否計入，都需先註冊。使用未校準的幻想附肢、人類指腹與人工橡膠探頭混成一個分母，不能作真實人體受器模型的品質證據。
