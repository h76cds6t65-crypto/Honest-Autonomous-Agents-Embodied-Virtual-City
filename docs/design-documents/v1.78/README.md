## 不能誤讀的事
1. 私人母版沒有上傳 GitHub。即使這裡有不少詳細章節，**149 項正式需求原文也沒有全部逐字公布**；尤其含私人關係、經濟及帳號內容的早期項目已抽象化或未公開。
2. 論文、資料庫目錄和實驗流程已整理，但 **OCT／PAD 校準尚未實測**；所有居民生活、Blender 資產及智能體程式均未完成。
3. 此 repo 是 **Public**，所以 Draft PR 分支也能被外界查看。本資料夾只保留已作基本去識別審查的文檔，不放私有原文、密鑰及未授權的角色圖片。
4. **P-02 不變**：開發前必須完成完整設計，並經匿名人類發起者最後明確批准；Github 文件不等於授權寫智能體程式。
5. **署名**：GPT（ChatGPT）為主要設計與文件撰寫同伴；原始構想來自匿名人類發起者；不聲稱三家 AI 廠商官方贊助。
