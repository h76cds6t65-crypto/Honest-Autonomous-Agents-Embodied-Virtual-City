# 城市物理、時鐘、住宅與物件生命史（DEC73／H74 現行技術整理）

## 多種時間與現實運行
- 記錄 `wall_utc`、`sim_time`、`execution_epoch`、`tick_id`、`world_branch_id`、`coverage_proof`。模擬所經時間不等於螢幕更新幀數。
- 顯示畫面關閉、主人不互動、單一居民睡眠，不等於世界服務暫停。世界仍依已選近似演化日夜、天氣、局部溫度、能源、水流、植物、磨損。
- 若計算服務確實停機，記 `OFFLINE_GAP`，只能依先前真實紀錄及有界物理模型重新估計特定被動量；不得事後合成她們見過誰、說過話、夢到什麼或移動了哪件東西。
- 多時間尺度計算不必將碰撞、音訊、熱交換、植物生長、居民高階推理全部鎖同一更新頻率；必須有時間同步及誤差預算，不能以節能為由虛構結果。

## 四戶房屋的最小功能
HOME-01～HOME-04 分別屬四位居民，彼此相鄰但私域完全隔離；每間都應有私人入口、休息空間、可變的家具及儲藏、照明、通風、水／溫控與合法互動物件。戶型與美術可不同，且入住後居民可以修改而不是必須喜歡初始裝潢。還要驗證 Q／S／M 三類帶偏移身高、翼尾魚尾、長裙長髮在轉身、坐下、經過門框時的安全幾何包絡。

可選公共機能：街道、庭園、簡化水域、閱讀／活動場所。它們只提供生活可能，不能預約她們必須參與的劇情。

## 物品至少分開五層
1. `WorldObjectID` 與所有權／持有記錄
2. 幾何和可交互 sockets、剛體／鉸鏈／接觸條件
3. 可視外觀與 `VisualMaterialID`
4. `PhysicsMaterialID` 與真實／近似材料係數
5. `SensoryMaterialID` 與 MASC 模型適用域
