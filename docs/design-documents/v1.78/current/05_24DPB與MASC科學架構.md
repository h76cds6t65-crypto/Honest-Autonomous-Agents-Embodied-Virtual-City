# 24-DPB、MASC、多尺度身體與感官驗證

## 系統範圍
四位居民應共用數位身體系統與感官處理架構，但各自擁有不同的 DPB 目前狀態、骨架與附肢模型、個人經驗及合法感知。生理代理追求**可信的外觀和可觀察反應**，不是完整複製人體細胞、神經、內分泌與免疫系統，也不把代理輸出當成真正神經或主觀痛覺。

**24-DPB 正規子模型編號尚未統一，屬三項硬性未決之一。** 不可以把舊版裸編號當作正式唯一 namespace。本章只描述跨子模型功能，不擅自指定 canonical DPB-01～DPB-24 名稱。

## MASC：材料—身體解剖—感官耦合
候選資訊方向：物件來源及材料狀態 → 幾何接觸和受力 → 局部皮膚或等效表面變形 → 受器代理（若有數據） → DPB、注意及 CAIA → 可選反應／動作。每階段須有標準單位、資料來源、不確定性、有效域和對應時間。

核心分離：
- `VisualMaterialID`：看起來如何，不直接保證摩擦或導熱真值
- `PhysicsMaterialID`：摩擦、彈性、厚度、濕度、磨損等可觀察／近似物理參數
- `SensoryMaterialID`：與皮膚位置、衣物中介、接觸方式相關的感官代理參數
- `WorldContactReceipt`：客觀接觸和力學
- `AttributionBeliefVersion`：居民以自己的感官、回想及信念理解該接觸的結果

## 已批准的 16 項感官深化方向（G64-01～16）
| ID | 工程重點 | 不得冒充的結果 |
|---|---|---|
| G64-01 | 自主探索接觸：壓、滑、抓、停止 | 不可強制每次探索 |
| G64-02 | 離線局部高保真與在線快速 ROM | 不表示 FEM 自動成真值 |
| G64-03 | 觸覺、視覺、聲學對時 | 單有時間戳不能視為同步 |
| G64-04 | 衣服、髮絲、外殼等中介層 | 不可將衣物外觸等同皮膚直觸 |
| G64-05 | 三種浮動形態的感官拓樸映射 | 不可按身高一倍縮放受器密度 |
| G64-06 | 低階姿勢保護與高階意圖分工 | 反射不是私人情感選擇 |
| G64-07 | 物件表面磨損與接觸歷史 | 只換貼圖不等於物性改變 |
| G64-08 | 多居民接觸同意與撤回 | 物理可達不等於有權觸碰 |
| G64-09 | 多層不確定性傳播 | 不可虛報未知感官真值 |
| G64-10 | 高幀率事件稀疏化與注意 | 每一幀不是一段自傳記憶 |

| G64-12 | 虛擬世界與現實感官邊界 | UI 的動畫不能改寫客觀事實 |
| G64-13 | 跨個體、跨條件校準及反例 | 不能只報訓練集漂亮數字 |

| G64-16 | 允許不知道某物真正材質 | 只看木紋不代表已辨別木材 |

## 多級運算架構
研究方向為**離線高保真校準候選 → 線上快速降階代理 → 身體低階反射控制 → 事件驅動認知**。局部高頻物理反應不依賴語言模型每一幀推理；非重要接觸不必全寫入自傳記憶。不同身體區域只有自己的數據已符合有效域時，才可宣稱採用相同模型。

## 特殊身體不能硬套人體參數
人指腹、手掌、腳底、穿衣接觸、龍尾、翼膜、魚尾是不同測量域。可借鑑真實蜥蜴、壁虎、魚類及薄膜力學，但不存在這些虛構附肢的真人受器真值。龍翼能否飛、魚尾能否游、皮下精確分布與主觀舒適度都不能單憑工程代理推斷。

**目前狀態：方向已規劃，24-DPB 命名未閉合；局部觸覺原始資料尚未取得和校準，沒有任何已通過的 FEM／ROM 模型。**
