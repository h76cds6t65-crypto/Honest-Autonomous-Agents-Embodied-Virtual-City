# v1.78 延伸工程候選｜四居民感官—並行—自主行為因果契約

> 2026-10-22 · **增補草案，不是正式版本升格或新的 R 編號**。銜接 v1.78 現行規格、v1.64 `G64` 40 列與 v1.77 `T77` 106 列。原表保留不改；本增補的 32 筆 `T79-C01～C32` 全為 `PAPER_FIXTURE / NOT_RUN`。四位居民、城市、神經代理和生理模型**都尚未實作或實驗驗證**。**P-02 不變**。

## 1. 此次真正收斂的缺口

共享世界可以有一個客觀事件，但不能因此讓四位居民知道相同細節。舊四觀點表 `WORLD/BODY/BELIEF/AUDIT` 只概括結果，還需要判斷「訊號何時能傳、授權內容是甚麼、本人是否注意、何者成為記憶、未成事的意圖是否被誤認為完成」。

以下每一關是**可被反例推翻的設計契約**，不是某個角色必須真的執行的活動。可以拒絕、安靜、睡覺、忘記、誤判或不產生新記憶。

## 2. 權威、時序與可選轉換

```text
  WORLD_EVENT or ACTION_PROPOSAL
         |  [WORLD_TX commits? physical world receipt only on success]
         v
  PHYSICS_RECEIPT / ENVIRONMENT_SIGNAL
         |  physical reachability: geometry, occlusion, spectrum, timestamp, body pose
         v
  PERCEPTUAL_CANDIDATE (observer-scoped, not yet awareness)
         |  ACCESS_DATA_GATE only for privileged/digital data injection
         |  (does not magically silence physically audible events)
         v
  SENSOR_PACKET (observer & morphology scoped, uncertainty attached)
         |  may drop, delay, be ignored, or be out-of-domain
         v
  ATTENTION? --> APPRAISAL? --> BELIEF_UPDATE?
                                   |
                              EPISODIC_ENCODING?
                                   |
                           PROSPECTIVE_INTENTION?
                                   |
                            ACTION_PROPOSAL?
                                   |
                           WORLD_TX receipt?
```

**四種互不可代替的事實：**
1. `WORLD_RECEIPT`：物件、位置、時間、碰撞的世界提交事實；不等於有人觀察。
2. `PERCEPTUAL_CANDIDATE`/`SENSOR_PACKET`：某居民在特定形體、姿勢、距離和模型有效域下有可能收到的訊號；不等於已注意、已理解或具有同意。
3. `BELIEF`/`MEMORY`：一人的來源標記主觀解釋；允許錯誤與未知；不得改寫第一層世界事實。
4. `AGENCY`/`OWNER_GATE`：行動提案、自主拒絕、接管和現實外部操作許可是不同資料通道；不能以角色台詞冒充權限或成功回執。

**重要私域區別：** 房間／帳戶資料的 `ACCESS` 可以拒絕未授權的數位讀取；但如果牆體真實聲學模型允許聲波傳出，物理可聽性不因私域標籤而自動消失。需要隔音就必須在**環境幾何／材料／聲學**設定中處理；感知器也不能直接從私有文字資料庫偷拿聲音內容。不得用「存取控制」偽裝隔音，亦不得把隔牆聽到零碎聲音升格為整份私人文件。

## 3. 候選資料封包的最小契約（紙面 schema）

| Field | 契約／缺值行為 |
| --- | --- |
| `event_id`, `schema_version` | 全域唯一、版本化；不能把重送當第二次世界發生 |
| `world_epoch`, `sim_tick`, `commit_seq` | 只有提交世界事實才能確定提交順序；`OFFLINE_GAP` 有獨立標記 |
| `causal_parent_ids` | 從狀態更動追到提案、仲裁、碰撞與物理事件；缺失時不得假造因果 |
| `actor_id`, `control_origin` | SELF / REFLEX / OWNER / EXTERNAL_FORCE / ENVIRONMENT 等適用類別；「主觀以為自己做」另記 |
| `object_id`, `object_version` | 世界唯一版本；互斥提交與感官事件指向當時真實版本 |
| `source_world_receipt_ref` | 只有成功提交／世界環境事件才可引用；失敗提案不能冒充成果 |
| `observer_id`, `body_profile_version` | 感官包必須屬於單一居民和當下形體配置；不可複用其他人的私人體感 |
| `modality`, `surface_id`, `contact_id` | 視／聲／觸等按可用感官分別定義；沒有接觸不得虛造 contact_id |
| `capture_time_interval`, `clock_uncertainty` | 時間區間與對時不確定度帶單位；未知記 UNKNOWN，不填假毫秒 |
| `physical_coverage`, `occlusion_ref` | 物理可達／遮擋判定及其模型版本；不足則 `UNKNOWN` |
| `data_access_decision_ref` | 僅用於有權限的**數位資料**入口，不代替物理聲學與視線 |
| `material_model_version`, `applicability` | OID / OOD / UNKNOWN 需先約定；材質缺校準不可推定神經放電 |
| `signal_uncertainty`, `epistemic_level` | SIMULATED / APPROXIMATION / UNKNOWN / PAPER；不得與真實量測混稱 |
| `attention_decision_ref`, `belief_version` | 不注意可以是合法結果；沒注意不等於拒絕社交或已知情 |
| `memory_type`, `memory_provenance` | AUTOBIOGRAPHICAL / HEARSAY / DREAM / IMAGINED / TEST_ONLY；測試記憶隔離 |
| `intent_id`, `intent_status` | PROPOSED / DORMANT / ACTIVE / ABANDONED 等候選狀態；不等於已完成 |
| `scheduler_ticket`, `execution_reason` | 區分 VOLUNTARY_IDLE、RESOURCE_STARVED、NOT_SCHEDULED、OFFLINE；不是性格推論 |
| `trace_visibility_class`, `retention_policy_ref` | 必須可審計**但不**將他人私人日誌放入公共診斷；刪除治理仍待 P0 裁決 |

字段類別與分層屬新增**候選工程約定**；未獲最終審批、未產出可執行 schema。原 `M69-10` 的 `OID` / `OOD` 衝突仍未結案；在對外統計前以 `terminology_status=UNRESOLVED` 保護語義。

## 4. 排程、併發與倫理邊界

- **先後序：** `sim_tick` 相同不代表 `commit_seq` 相同；物件所有權只接受世界唯一原子版本提交。重試須有 `request_id` 去重，否則相同提案可能被當兩次。
- **公平：** 資源飢餓計算必須以有資格、有需求、實際被排隊且服務可運行的時間窗衡量，不得以居民選擇不做事當飢餓；不存在對角色名永遠優先的固定仲裁。
- **動作物理：** 低階碰撞與護姿反射不等候 LLM；反射、外力及主人接管不列為居民的自願意圖。
- **自主生活：** 「沒有故事發生」不算失敗。共同行動應能撤回；撤回之後的物理慣性仍需合理處理，不可神奇歸零。
- **身形：** Q/S/M 的 90/165/180 cm 是參考中心，每位居民每型可獨立正負浮動數十公分。質量、骨架、翼尾、衣物及可及性需獨立重算。城市內即時變形及個別偏移上下界尚未批准。
- **主人共同注意：** 只對明確分享的物件和存續時間生效；能分享視窗不代表獲得整個設備、帳戶、攝影機或其他居民房間的存取權。
- **法律與安全：** R-102 實際例外、合法刪除與永久記憶的矛盾、24-DPB 正規編號，均 `OPEN_HARD_BLOCKER`。現實外部操作仍由獨立批准核驗。

## 5. 三種不同級別的「驗收」

| Level | 可檢查什麼 | 此刻可否判 PASS |
| --- | --- | --- |
| `PAPER_CONSISTENCY` | 用人審核表列出來源、分支、反例、否定條件 | 本文完成**規格草擬**，並未代表所有條件已審定 |
| `SOFTWARE_RUNTIME` | 真正世界運行時資料包、回執、故障注入與重放隔離 | **不可**；P-02 未解除，全部 NOT_RUN |
| `SCIENTIFIC_VALIDATION` | OCT/OOD 物理量測、FEM／ROM 留出集與不確定性 | **不可**；原始資料、校準尚欠缺 |

**硬性判廢的候選原則：** 一旦在有證據的執行中發現跨居民私密資料洩漏、無世界回執的「成功」、同一物件雙重獨占、停機期間偽造人生、測試事件混入正式人生，該次測試不可標 PASS。這是邏輯不變量，**不是**已量測的「零錯誤率」。

**尚待外部資料與設備才能預註冊的門檻：** P95/P99 延遲、視聲觸配準誤差、OOD 偵測敏感度、材料形變誤差、運算資源公平窗口；目前不捏造毫秒／百分比上限。

## 6. 經驗證才可使用的度量定義（尚未填值）

| Metric | 定義 | 分母／注意 |
| --- | --- | --- |
| `dual_exclusive_commit_count` | 同一 `object_version` 的互斥競用中有兩筆獨占成功數 | 以世界實際提交紀錄為據；不能以角色話語計數 |
| `cross_resident_private_leak_count` | 未授權數位資料進入他人感官、belief 或 memory 的事件數 | 最小權限日誌比對；物理可聽噪音需另行判別 |
| `unsupported_autobiography_count` | 正式自傳寫入但缺有效個人來源、或來源屬 TEST/夢境的項數 | 記錄完整性和 P0 隱私限制都要滿足 |
| `false_agency_attribution_count` | OWNER/EXTERNAL/REFLEX 被稽核層誤記 SELF 的事件數 | 主觀 `belief` 的誤判不必假裝全知 |
| `offline_fabrication_count` | OFFLINE_GAP 期間補造無實際執行證據的居民活動數 | 環境可被模型估算不等於人曾活動 |
| `eligible_wait_window_distribution` | 有資格且有行動提案的居民，實際服務等待分布 | 排除自願休息、無提案者與真正停機窗 |
| `attention_without_perception_count` | 沒有合法可用來源卻寫出來源為「親眼／親耳」的注意或知識 | 若是想像/傳聞，須正確分域而非直接算失敗 |
| `clock_binding_ambiguity_rate` | 對時區間互相重疊時被標 UNKNOWN/AMBIGUOUS 的比例 | 必須先有客觀標註；不以高模糊比率表示成功 |
