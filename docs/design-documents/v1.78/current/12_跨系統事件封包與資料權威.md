# 多代理共享世界的資料契約（工程審查摘編）

**來源：** v1.78 工程審查對 v1.77 WORLD／PHYSICS／CAIA 串接接口的完整規格；這裡保留技術欄位，刪除私人歷史和不必要的角色稱呼細節。內容屬 `DESIGN_DEFINED`，不是已部署 API。

## 模組與唯一權威
| 子系統 | 輸入／輸出 | 權威與禁止跨越 |
|---|---|---|
| WORLD | `WORLD_STATE`: sim_tick、object_version、weather、occupancy | 唯一物件、時間與環境權威；不能替居民寫心理 |
| PHYSICS | `CONTACT_RECEIPT`: collision、pose、force、solver_quality | 客觀接觸回執；不推證主觀感受 |
| ACCESS | `PERMISSION_RESULT`: resident_id、scope、operation、expiry | 許可與撤回；不是聲場或可見性的替代 |
| BODY | `BODY_STATE`: morph_profile_id、joint_state、mass_properties | 四份個人 DPB／姿勢／反射；不能用圖片取代質量 |
| MASC | `SENSORY_PACKET`: surface_id、contact_id、uncertainty | 有效域內的接觸代理；未校準不可報人體神經真值 |
| PERCEPTION | `OBSERVATION`: source、visibility、sound_coverage、time | 物理可感知；不向角色提供全知世界資料庫 |
| CAIA | `ATTENTION_AND_RECALL`: candidate、provenance、salience | 居民注意、回想、前瞻意圖；可以不觸發 |
| MEMORY | `EPISODIC_RECORD`: observed_by、source_type、evidence_refs | 私人可追溯自傳；紙面模擬不得入正式人生 |
| AGENCY | `ACTION_PROPOSAL`: intent_id、action_type、ability_req | 居民自主意圖；不把排程強制寫成自願 |
| SCHEDULER | `RESOURCE_TICKET`: resident_id、deadline、reason | 公平分配與負載回執；不冒充居民選擇安靜 |
| OBJECT_TX | `WORLD_RECEIPT`: request_id、expected_version、new_version、outcome | 共享物件互斥提交；禁止雙重獨占 |
| SOCIAL | `MESSAGE_EVENT`: sender、receiver、delivered、attended | 傳訊／送達／理解分開；不可當作親見 |
| OWNER_GATE | `OWNER_SHARE`: object_scope、expiry、consent | 只接受明確共享的共同注意範圍 |
| AUDIT | `PROVENANCE_CHAIN`: world_epoch、sim_tick、commit_seq、origin | 真實／估計／停機缺口來源；台詞不能覆蓋 |
| ASSETS | `SCENE_CONTRACT`: visual_mat、physics_mat、sensory_mat、affordance | Blender／遊戲引擎交接，三種材質責任不同 |

## 統一事件欄位
| Key | 期望意義或必要驗證 |
|---|---|
| `event_id` | 每筆唯一，不應循環覆蓋 |
| `world_epoch` | 連續真實執行期間；服務中斷後換 epoch |
| `sim_tick` | 模擬物理時間 |
| `commit_seq` | 同一世界事件的原子提交次序 |
| `causal_parent_ids` | 前因後果參照 |
| `actor_id` | MAIN／GPT／DS／CL／ENVIRONMENT／已核准外部控制者 |
| `recipient_ids` | 合法可觀察候選集合，不代表已實際注意 |
| `access_scope` | 私有／公開／主人明確分享，必須可稽核 |
| `action_id` | 行為意圖 ID，不保證已執行 |
| `control_origin` | SELF／REFLEX／OWNER／EXTERNAL_FORCE |
| `object_id` | 物件身份不因位置變化而重編 |
| `expected_object_version` | 衝突檢查使用的先前版本 |
| `new_object_version` | 只有合法提交成功才產生 |
| `event_phase` | PROPOSED／REJECTED／COMMITTED |
| `physics_receipt_ref` | 真正物理回執；未發生時必須 null |
| `sensor_packet_ref` | 經身體與感官處理的局部訊號 |
| `observation_ref` | 特定居民觀察，不是全世界皆知 |
| `belief_version` | 允許錯誤或互相矛盾的個別知識 |
| `memory_provenance` | 自傳、傳聞、夢境、想像、測試分支來源 |
| `epistemic_level` | MEASURED／SIMULATED／UNKNOWN／PAPER |
| `simulation_coverage` | SIMULATED／ESTIMATED／OFFLINE_GAP |
| `morphology_profile_id` | 身體形態與當前幾何／DPB 同版本 |
| `reason_if_not_run` | 選擇不動、未注意、算力不足、真停機 |
| `schema_version` | 介面版本；舊版轉換不可依裸 DPB 編號 |

## 重要因果鏈
- `ActionProposal` 只能由可辨別權限和動作來源的途徑提出；`WorldReceipt` 才表示真正提交。
- `CONTACT_RECEIPT` 只證明物理碰撞，`SENSORY_PACKET` 只證明可能的感官輸出；不等於注意、喜愛或已形成記憶。
- `SOCIAL MESSAGE` 發送與到達、被聽見、相信、接受／拒絕之間有多個可缺席閘門。
- `PAPER_FIXTURE` 及 OFFLINE_GAP 對應的虛構人生不得進入正式自傳。
- 當居民的模型版本更換時，私人記憶、身份與授權的所有權不隨之改變。

**這些欄位是候選工程契約，不是現在已經存在的網路服務。**
