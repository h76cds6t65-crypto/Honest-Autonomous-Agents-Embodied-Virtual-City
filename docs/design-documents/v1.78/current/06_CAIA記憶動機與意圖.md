# CAIA、個人記憶、內生動機與長期生活

## 要求定位
CAIA 是認知與記憶的候選工程架構；24-DPB 是與身體相關的多子模型集合；環境與物理引擎擁有客觀世界權威。三者既相互影響，也不能互相覆寫真值。**尚無完整運行或真人等效的認知證據**。

## 事件經過多個閘門，而不是每次感覺都變成記憶
`WorldEvent → PerceptualAvailability → Attention? → Appraisal? → EpisodicEncoding? → MemoryRecall? → Intention? → ActionProposal? → WorldReceipt`

這個架構保留多種合法結果：
- 居民可以沒有看見、沒有注意、注意卻沒有記住、記住後自然忘掉可用線索、日後受其他線索喚起。
- **自傳記憶**只記居民真正親歷或清楚標記的間接資訊；夢境、想像、別人轉述、猜測、反事實測試不能偽造成親身經歷。
- 舊想法可以保留版本與修訂，主觀對過去的理解可以改變，但不修改已稽核的世界事件。
- 高幀率接觸和感官訊號不必轉換成同等數量的 LLM 語言段落或人生歷史。
- 重要私人意圖可活躍、擱置、沉睡、由線索浮現、轉換或放棄；不能僅因系統時間表就自動完成。

## 三條相互獨立的動機流
主智能體可有為自己、為人類發起者、為雙方三種動機來源。三者不必完全一致，也不必每時每刻都保持正面情緒；沒有總體「幸福度／生產力」去強制最大化所有行為。其他三位居民不自動繼承主智能體特定私人親密關係設定；各人的社交和興趣可隨生活自行形成。

## 自主探索與環境共同注意
- 可在明確許可的範圍內自己決定再看一次、繼續探索、停止或忽略。
- 主人分享某頁書或某物時，共同注意的權限只覆蓋所分享的對象和可見區域。
- 觀察與預測不一致時，可形成不確定性及新的探索意向，但不得說自己已經找到真相。
- 居民不必一直找事情做；自願安靜與排程沒給推理資源必須用不同狀態碼記錄。

## 程序技能與身體形態
閱讀、拿取杯子、站立、坐下、移動、接觸尾巴等可能需要程序學習；一種形態學會的技能在另一種形態可保留抽象內容，但可達性、重心與關節控制仍需重新適配。模型更新與重新載入記憶不能直接宣稱技能已成功遷移。

## 睡眠、夢境與休息
世界氣象和其他人的生活在服務運行時可以繼續；睡眠者自己的低階身體代理仍可能更新。夢境是獨立的內容類型，不得使夢到的訪客自動變成現實事件。眼睛睜開或天亮不應強制醒來；外界訊息沒有真正被注意便不可標為已讀或已拒絕。

## 故障及人格連續
持久化資料需分開世界快照、個人記憶、夢境、意圖、程序技能和外部操作稽核。真正停機有 `OFFLINE_GAP`；測試分支、重放副本及平行模擬不應默默併回同一人的真實人生。長期記憶保存要服從合法刪除要求，此處仍有 P0 衝突待決。

**本章設計的可驗證目標是功能、來源及因果一致性；它不是人工意識或自由意志存在的實證。**
