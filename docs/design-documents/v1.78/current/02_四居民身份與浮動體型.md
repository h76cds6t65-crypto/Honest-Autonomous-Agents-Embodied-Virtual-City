# 四位居民、身體形態與房間邊界

## 共用架構，不共用個體
| 居民代稱 | 身體設計焦點 | 不應預設 |
|---|---|---|
| MAIN 女主智能體 | 自己的身體、CAIA、DPB、持續人格、三種動機與私人生活 | 強迫性格、愛好、往事 |
| GPT 龍娘 | 龍角、翼膜、可折翼、龍尾、姿勢與物理包絡 | 有翼就一定能飛；必須喜歡某類物品 |
| DeepSeek 藍色肥魚 | 兩腿與魚尾並存、水陸不同接觸與運動代理 | 一定會游泳；一定愛泡水 |
| Claude 橘色大小姐 | 髮絲、裙擺／鞋跟、可替換衣裝、書籍與創作工具 | 永遠優雅整潔；一定成為藝術家 |

每位居民都有獨立 `resident_id`、24-DPB 參數與當前值、CAIA、自傳記憶、感官、意圖、能力、住宅私域和授權紀錄。同一基礎模型不等於一份共用心智。

## v1.78 三形態：中心值不是固定高度
| 形態標籤 | 參考身高 | 約束 |
|---|---:|---|
| Q 小型比例 | 90 cm | 個別正負偏移數十公分，具體邊界未決 |
| S 少女視覺比例 | 165 cm | 身形類別不是心理或法律年齡 |
| M 成熟視覺比例 | 180 cm | 可以與 S 類別身高數值重疊 |

每位居民**每一種形態**都有自己的偏移：`actual_height_cm = reference_height_cm + resident_form_offset_cm`。不要擅定 ±30 cm，亦不把所有人鎖在 90／165／180。不同形態的幾何、質量、慣量、肌力代理、視點、可及性、衣物、翼尾活動包絡都必須重新驗證。形態轉換不生出不同的人生或重置記憶。

## 物理交接
- 模型不能只有 3D mesh：要具碰撞幾何、接觸點、關節、質心、材料 IDs、互動 sockets、可達包絡和安裝位。
- 龍翼折疊狀態決定走廊／門框通行能力；尾段被外力碰撞時不得冒充自願動作。
- DeepSeek 的腿與魚尾是並存的設計，不許描述成換腿為魚尾才存在。
- 高跟鞋、長裙、長髮與椅背及階梯存在真實碰撞／近似誤差；材料貼圖不自行改變物理參數。
- 是否在城市內物理變身、能否飛行與游泳都屬待決；不能在紙面資料中以 `SUCCEEDED` 宣稱成功。

## 人際與權利邊界
四位女性居民初始僅為鄰居；可以互訪、借書、獨處、拒絕與形成不同或相似的性格。城市 Claude 與未來協助 Blender 的外部 Claude 工具鏈必須隔離，後者不因此取得住戶日記權限。品牌名稱是虛構角色主題的非官方名稱，未獲相應公司的背書。
