# PAD-A／B／C／D 與真實實驗證據界線

這是研究設計和來源註記，不是本專案已取得原始資料、完成生理模型或操作智能體的證明。研究目前依發起者決定**暫緩**，優先處理系統規格。

## 研究順序
| 階段 | 對量問題 | 必須觀察 | 當前限制 |
|---|---|---|---|
| PAD-A 法向壓入 | 平板上皮下局部位移與可能估計的 2D 應變 | 真正 OCT 幀、位置/像素尺度、同步受力與可追蹤點 | 原始資料未下載，不能報誤差 |
| PAD-B 切向剪切、黏著與滑移 | stick/slip 時間及局部橫向位移 | 位移、切向速度、法向預載、若可得真實切力 | 不可由刺激目標反推實測摩擦 |
| PAD-C 動態局部變形 | 低頻形變隨時間的變化 | 實際影像取樣時序與低頻可見變形 | 10 Hz OCT 不能直接建立高頻真值 |
| PAD-D-H 真人指腹材質掃動 | 人體表面接觸的可量測滑動訊號 | 速度、力、振動與材料 ID | 不能從外部波形推定神經受器放電 |
| PAD-D-R 人工探頭材質掃動 | 人工橡膠探頭的速度／方向依賴 | 力、方向、速度、探頭加速度/聲學等 | 非真人皮膚域，不可直接混用 |

## 局部物理精度的誠實報告
- 必須分開 **FEM 對人類實測**、**ROM 對 FEM 近似**、**ROM 對人類實測** 三種比較。
- 模型預測不能自稱量測真值。對比時須相同座標、單位、試驗條件與可觀測量。
- 以受試者、材料、速度、方向等成組留出，不以同一長波形相鄰窗分割造成資料洩漏。
- 原始來源、版本、授權、檔案 SHA-256、時間戳與不確定性必須可追溯。
- 若無可靠內部皮下應變標籤，只能比較實際可觀測的位移或外部訊號。
- PAD-C 若研究 OCT 約 10 Hz 採樣，未另取得相容高頻儀器量測前，不報告 20、100 或 300 Hz 皮膚變形為已實測。
- 未知的幻想附肢受器密度、翼膜感受等一律 UNKNOWN 或類比假說，不能假造人體真值。
