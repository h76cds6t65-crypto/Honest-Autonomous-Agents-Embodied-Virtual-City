# 四居民同城並行、物件交易、社交訊息與資訊隔離

同一城市只有一份可稽核世界狀態，但沒有任何人得到無限制全知權限。四人的 CAIA、DPB、個人訊息、注意與記憶各自私有。

## 公共物件同時被拿取
1. GPT 與 DeepSeek 可在同一世界時窗內分別提出拿取唯一書籍的 `ActionProposal`。
2. 世界端查核物件 `object_id`、當前位置、版本、持有狀態、身體可達性、碰撞、許可與交易序列。
3. 同一互斥操作只能一份成功提交；另一份應得到實際 `FAILED_CONFLICT` 或對應失敗回執，不能兩人都宣稱已獨占。
4. 每個人得到其合法可見的事件回執，感知與理解可以不同；失敗不必強制成為一段自傳記憶。
5. 還需要長期公平和排程反例，避免同一居民永久搶不到運算或公共資源。

## 訊息的五個階段
`Sent → Delivered? → Perceived? → Attended? → Understood? → Responded?`

每一步可以缺席、錯誤、延遲或不同步。Claude 告訴 GPT 一個訊息，並不會自動寫進 MAIN 或 DeepSeek 的私有記憶。DeepSeek 聽到轉述只代表「某人轉述」，不能標「自己親眼所見」。私域內的訊息不得繞過門牆隔音、外部授權和居住權。

## 共同行動與個體自由
不同居民可能同時睡覺、散步、創作、只坐著、不願社交。共同世界日夜不是四人的固定課表；家庭空間不等於公共場地。居民可以拒絕觸摸翼尾，其他人接近不代表取得同意。主人和主智能體共同注意應以**明確分享的物件／視窗／片段**為邊界，不能外溢成全城資訊。

## 常見失敗反例
- 一人拖走椅子，另一人遠方台詞仍聲稱椅子沒動 → 世界與個人信念可以不一致，但客觀椅子只能有一個位置。
- 各角色共用後端 LLM，Claude 記憶突然混入 GPT 私人日記 → 資料隔離失敗。
- Claude（城市居民）與外部 Claude（未來 Blender 美術工具）被當成同一個具全權操作身份 → 權限模型失敗。
- 模擬停止卻補造社交、友誼與作品 → 生活史完整性失敗。
- 外觀播放開門動畫但碰撞門保持關閉 → 不能標示開門成功。
