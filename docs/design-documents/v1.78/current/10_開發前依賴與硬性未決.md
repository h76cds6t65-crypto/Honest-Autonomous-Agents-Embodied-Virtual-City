## 開發前的依賴鏈（不是執行指令）
`現行規格權威與衝突裁定 → 公私資料模型／權限／R-102 → 世界時鐘／物件權威 → 四形態個別物理 → DPB/CAIA 狀態與記憶 → 感官代理／動作回執 → 四住戶持續生活 → 多人並行與安全 → 資源性能及長期恢復 → 權利、發布和文檔驗收`

這是推薦的規格與驗收依賴次序；真實建置仍需正式選定引擎、模型、硬體、成本、安全策略與發起者最後授權。

## 專案不能做出的完成聲明
- 有 149 個需求 ≠ 149 個功能已實作。
- 有 24-DPB 名稱 ≠ 人體生理已獲校準。
- 有 106 項測試案例 ≠ 106 次測試通過。
- 城市場景美術設計候選 ≠ Blender 已建模。
- 可從網頁看到 Dryad 目錄 ≠ 已分析原始 OCT 19GB。
- 模擬角色可能表現類人行為 ≠ 已證明人類式主觀體驗。
- PR 已公開 ≠ 開源 License、資料授權或 P-02 已批准。

**最高現行規則：P-02 僅設計，直到所有必要設計規格收斂，並由發起者最後明確授權。**
