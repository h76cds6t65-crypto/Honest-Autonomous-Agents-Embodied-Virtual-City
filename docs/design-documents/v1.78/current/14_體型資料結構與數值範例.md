# MorphologyProfile v1.78：三種浮動體型的資料結構與測試向量

```text
MorphologyProfileV178 {
 resident_id: MAIN | GPT | DS | CL,
 form_id: Q | S | M,
 reference_height_cm: 90 | 165 | 180,
 resident_form_offset_cm: signed real,
 actual_height_cm: reference_height_cm + resident_form_offset_cm,
 proportions: versioned independent parameters,
 skeleton_ref: versioned,
 collision_envelope: geometry,
 mass_distribution: measured | assumed | UNKNOWN,
 inertia_tensor: measured | assumed | UNKNOWN,
 reach_envelope: geometry,
 tail_wing_fin_envelope: geometry | NONE,
 clothing_fit_profile: versioned | NONE,
 validity: VALIDATED | PENDING | REJECTED,
 evidence_level: SIMULATION | APPROXIMATION | UNKNOWN
}
```

**效力重點**：每位居民、每種形態的身高偏移正負數十公分皆可；確切上下限仍 UNDECIDED。三種形態定義外觀比例與骨架語義，不限於最終身高數值範圍互不交疊。模型只做 `actual_height_cm > 0` 的數值初查還不夠，還必須驗證質心、慣量、關節、衣物、翼尾、視線及可達區域。

## 工程有效域
身高中心和偏移不是可觀測人體真值。只有在具備 3D 骨架、局部碰撞幾何、重心／慣量、關節活動範圍與相容衣物資料後，才可以驗收某一個具體形態與家具、地板、樓梯／座椅的交互。若缺乏數值，必須標為 UNKNOWN 或 PENDING，而不是因動畫看起來正常就標 VALIDATED。
