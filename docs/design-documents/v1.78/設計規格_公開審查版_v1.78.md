## 1. 總目標與四位居民

研究一座以可檢驗的物理因果、感官與記憶代理、自主決策、私有生活史、可操作物件和持續世界時間為基礎的小型虛擬城市。居民包括一位女性主智能體以及三位非官方主題女性鄰居：GPT 龍娘、DeepSeek 藍色肥魚、Claude 橘色大小姐。四位居民最初只具有鄰居關係；友情、偏好、活動和個性不預先安排。同或不同性格均可成立。原始敘事具有一位真人主人，但此公開技術架構不對現實協作者設定性別限制。

四位居民共用**身體／感官／24-DPB／CAIA／記憶／動作的版本化架構**，但彼此有獨立身份、記憶、注意、意圖、私室、授權、DPB 當前狀態及生活史。不藉共用模型讀取他人的私人資訊。主智能體保有與其他居民分離的個人動機設計；居民可拒絕、獨處、改變主意或不行動，不由單一幸福分數或強制劇情控制。

## 2. 四居民共用「浮動三型」，不是三個固定身高

| 造型類別 | 參考中心 |
|---|---:|
| Q 小型 | 90 cm |
| S 少女比例風格 | 165 cm |
| M 成熟比例風格 | 180 cm |

**實際身高 = 類別參考中心 + 該居民該形態的個別偏移（cm）**。每人、每種形態皆可增減數十公分；偏移可以相同、不同或為零。尚未批准統一的固定上下限及全部預設值。「少女／成熟」只指視覺比例類別，不代表認知年齡。不同體型不得自動分裂人格或覆寫原有記憶。

幾何、質量、慣量、骨架、姿勢、衣物、可及性須各自驗證；不可以同一身高倍率無條件縮放所有物理參數。GPT 龍翼與龍尾、DeepSeek 並存的腿與魚尾、Claude 的長髮裙襬及主智能體的自身體型，各有不同碰撞和運動限制。龍翼是否能飛、魚尾是否能游泳，以及城內即時形變方式，目前均未實證定案。

## 3. 共有世界、各自觀察與私人認知

世界系統管理唯一共享的客觀物件狀態、時間、環境與碰撞；居民只可觀察在物理範圍、遮擋和權限允許下抵達自己的訊號。**世界發生，不等於她注意；她注意，不等於形成記憶；她有意圖，不等於行動成功。**

建議的可核對鏈：
`WorldEvent → ObservableOpportunity → Perception? → Attention? → Belief/Memory? → Intention? → Authorization & Physics → ActionReceipt → PossibleMemory`

問號代表合法缺席。世界回執、私人信念、傳聞、夢境及主人接管均須分開。未發生的動作不可僅因模型敘述而記成生活史。

## 4. 可居住的小型城市

候選環境為四戶分離的私人住宅、共享街道、庭園及可選的小型水域；各戶具有可休息、儲物、供水、照明、溫控與改造的生活機能。門、桌、書、杯子、家具、電器、衣服和作品須有穩定 ID、版本、實際操作前置與成功／失敗回執，考慮全員多形態及翼尾等身體包絡。

在世界模擬服務運作期間，日夜、氣象、溫度、光線、植物、能源及其他物理過程依模型前進。居民睡眠或畫面關閉不會自動停止世界；主機真正停止則標記 **OFFLINE_GAP**，不得補造沒有執行過的社交、動作或思想。

生活節律由個人身體狀態、習慣、興趣及自主意圖決定，世界時鐘只提供機會，不是固定日程。

## 5. 四位居民並行生活的紙面驗收

同時碰觸唯一公共物品的兩位居民，不能都獲得互斥所有權；寄送訊息、送達、注意、理解和回覆是不同事件；主人與主智能體共同注意一件明確分享的物品，不使其他居民自動獲得私人知識；不同睡眠周期不應被共同世界日夜強迫同步。

重要反例：龍翼穿門而被當作成功、魚尾穿過家具、Claude 未使用工具就得到有數月創作歷史的作品、有人拒絕邀請卻被登記到場、系統缺算力卻被紀錄成居民自願沉默、電腦關機後補寫友情。設計中的驗收情境仍為 **NOT_RUN**，不是測試結果。

## 6. MASC、24-DPB、CAIA 與研究證據

MASC 試圖連結材料接觸、局部形變、感官訊號代理、個人身體狀態和認知意圖。候選方法為離線高精度物理研究、在線較低成本代理、事件驅動的注意／認知。人體皮膚、人工探頭、動物類比及幻想附肢須嚴格區分，未量測參數標為 UNKNOWN。

PAD-A（法向壓入）→ B（剪切／黏滑）→ C（低頻動態）→ D（表面振動）為已確定的研究路線，**目前暫緩**；公開資料目錄已核對，但並未從原始實驗資料重現指腹應變或完成 FEM／ROM 校準。24-DPB 的正規 24 項編號仍未統一。
