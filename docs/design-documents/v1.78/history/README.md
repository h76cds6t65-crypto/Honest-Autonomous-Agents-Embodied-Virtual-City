## 為何不直接把私人 256 頁完整上傳？
歷史母版包含多版重複紀錄、私人背景和可從多個細節交叉識別個體的內容，以及舊版權限條文的法律／安全效力疑問。簡單刪名字無法提供充分的隱私保護；我們選擇**重寫現行技術規格並記錄舊版演變**。缺少的資料會在[覆蓋清單](../公開覆蓋與刪除紀錄.md)中透明列出，而不裝作已完整公開。

## 版本遷移時的反例
1. 不能把 v1.59 當時僅對 DeepSeek 明確提出的三型，解讀成 v1.78 只有 DeepSeek 可用三型。
2. 不能將 v1.54 的候選強制 API 方案覆蓋後來取消強制供應商連接的決議。
3. 不能將早期永久記憶措辭解讀成有權拒絕合法個人資料刪除。
4. 不能將舊版 R-102 的「規則反抗」描述當成無條件對現實資源越權的許可。
5. 不可把文獻查詢、紙面案例或未校準 FEM／ROM 寫成工程 PASS。
