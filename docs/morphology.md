# 共用三型浮動身高 / Morphology v1.78

四位居民 **MAIN、GPT 龍娘、DeepSeek 藍色肥魚、Claude 橘色大小姐** 均有 Q／S／M 三種可配置體型。

| 類別 | 參考中心 |
|---|---:|
| Q 小型 | 90 cm |
| S 少女比例型 | 165 cm |
| M 成熟比例型 | 180 cm |

**這是參考值，不是固定身高**。對每位居民的每種體型，實際身高 = 類別參考中心 + 專屬偏移。偏移可為正、零或負，且可達數十公分；精確上下界未批准，不可擅自設定固定 ±30 cm 政策。

類別代表造型架構，並不等同生理或心理年齡。三型可以在公分範圍上重疊。骨架比例、重心、慣量、碰撞、可及性、服裝、龍翼／龍尾／魚尾必須分別驗證。改變身形不應重置原有身份、記憶、動機與權限；是否允許在世界中即時物理變形尚未決定。
