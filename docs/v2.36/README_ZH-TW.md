## 長時配對、事件與熱帳

- **C32-04 至 06。** 同一 S 型靜息代理與同一 WORLD 回執，兩個 BDF 設定各跑無碰撞、純原方程碰撞及加一次被動阻尼熱。碰撞後 1／24／72 小時都重現原方程約 −0.000311111 J 的熱缺口。補入熱的分支，三窗的原總帳最大殘差約 3.54×10⁻⁶ J，門檻為 2×10⁻⁵ J。72 小時血液氧約為初值的 72.48 倍，組織氧約為 58.92%。無碰撞對照也重現分布漂移，供體下界、守恆及分布校準分開判定。
- **C32-07。** tick 25、265、865 依右、左、右各提交一次。依序與擾動送達產生逐位元相同的回執與 1,108 筆取樣。三筆接觸耗散約 7.466666667、0.114302246、0.029170791 mJ，合計約 7.610139703 mJ。連續阻尼另記約 0.379203793 mJ。提前或衝突請求遭拒，同內容重送取回原回執。
- **C32-09／10。** 單機 SQLite WAL／FULL 的身體適配器在指定停點遭 SIGKILL。提交前案重開只見已持久的 revision 0 與零筆身體效果、物理帳和回執，確認後重送才持久化。提交後案重開讀回 revision 1 與原 APPLIED 回執。後續重送對已提交事件都呼叫適配器零次，持久效果各一次。兩案都對照連續基準的狀態與回執，呼叫端的回執缺失先記 IN_DOUBT。
- **C32-11。** 供氧在第 900 至 2700 秒中斷，三撞跨過復供。自然斷供配對在斷供及恢復窗的 24 類供體均非負，三次碰撞的瞬時庫存改變皆為零。原版全窗另有四條 FAIL_NUMERICAL。人工零庫存用四項原導數為零的約束及復供後 0.1 秒顯式啟步，另驗自然汗膜的起始啟步。五條候選的原始記錄均非負。

## 求解器與收斂界線

C32-13 用同初值、事件、容差及步長上限比較 BDF 和 Radau。熱負荷與自然斷氧長窗包含末次預定撞擊後 24、72 小時，65 維最大縮放差約 1.63×10⁻⁸，門檻為 2×10⁻⁶。無護欄的人工零庫存，BDF 復供約 0.61 ms 的組織氧與 ATP 約 −1.79×10⁻²² mol、−5.55×10⁻²³ J，Radau 記錄值非負。接受步點與稠密中點保留這項 SOLVER_DEPENDENT_STRICT_ZERO 分歧。套用相同護欄後兩法的 24 類供體記錄皆非負。
