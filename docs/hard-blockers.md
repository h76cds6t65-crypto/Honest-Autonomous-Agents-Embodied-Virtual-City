# P0 硬性未決事項（OPEN）

## BLOCK-78-01 永久／長期記憶與合法刪除
必須設計資料分類、保存期限、刪除權、撤回流程，涵蓋索引、快取、副本、備份、訓練衍生資料及最小稽核。不得宣稱「永久記憶」可以凌駕個人資料保護義務。法律適用與需求原文待核對。

## BLOCK-78-02 R-102 原文與權限
需從私人正版需求中逐字核對 R-102 及歷史例外，建立 D0／D1 和不同外部操作類型的授權矩陣、撤回、接管與可稽核回執。在此之前，不以本倉庫文件授權對現實 Windows、郵件、付款或設備執行操作。

## BLOCK-78-03 正規 24-DPB 編號
對所有版本的 24-DPB 名稱、別名、衝突編號製作來源與歷史交叉映射。不得單憑相同數字視為同一個生理子模型。

任何 BLOCK 不因提出建議就自動關閉；需可測試規格、版本相容說明、所有者審核與必要合規檢查。
