# PUBLICATION PRIVACY GATE / 公開前隱私與權利檢查

**狀態：草案。任何資料通過此檢查也不代表已獲授權自動公開。**

## 必要檢查
1. **分類來源**：僅公開專門編寫的公共規格；私人完整母版、個人對話紀錄、身份與生活細節均預設禁止發布。
2. **清除識別資訊**：姓名、帳號、住址、學校、工作、金錢、精確時間位置、相片中的 metadata、個人檔案路徑與 Git 提交 metadata 等，逐項查看。
3. **秘密掃描**：API 金鑰、token、密碼、憑證、private key、內部網址及 .env 絕不提交。
4. **第三方權利**：B 站角色圖、品牌標識、模型、研究資料及 Blender 資產需查核原權利與發布許可；不因公開專案而取得權利。
5. **權限與安全**：不能公開直接授予 Windows/支付/郵件/網路外部動作權限的敏感憑證或配置；R-102 必須依原文正式決議。
6. **科學誠實**：標記設計、假設、未驗證、實際完成；沒有實驗就標 NOT_RUN。OCT/生理數值不得冒充實測。
7. **追溯風險**：警惕多個看似匿名的細節組合仍可重新識別人，並檢查 Markdown、CSV、DOCX 的作者、修訂與隱藏 metadata。
8. **公開檢視**：新內容先以 Draft PR 提出；核對 diff、文件歷史、附加檔案與授權，**由專案擁有者明確決定是否合併及公開**。
9. **事故處理**：誤公開時，立即撤下與撤銷金鑰，評估 Git 歷史、快取、fork 和第三方保存；刪除 GitHub 檔案不保證全網資料消失。

## 可公開與不可公開
- **可公開候選**：匿名化的需求摘要、規格介面、測試規則、研究方法、必要的來源引用、合成例子。
- **預設不公開**：完整原始對話、未授權圖像、私人生活細節、實際居民記憶、外部系統憑證、未取得散布授權的第三方素材。

## 發布節奏
不因「時間到了」而自動降低隱私標準。可以定期**準備候選變更與審查報告**，但公開合併前需完成所有必要檢查及所有者核准。
