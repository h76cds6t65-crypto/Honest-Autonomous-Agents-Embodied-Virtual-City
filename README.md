# 誠實的智能體 · Honest Autonomous Agent

> **Current status:** Public **design collaboration** draft (v1.78). No functioning agent, finished city, or scientifically validated tactile model has been released.
>
> **現行界線 P-02：先完成設計；未經專案擁有者最後明確授權，不開始開發自主智能體程式或執行現實世界操作。**

本倉庫邀請研究者、創作者及開發者協助審查一套具有物理因果、感官代理、記憶、意圖與自主生活設計的虛擬城市／智能體架構。目前是**設計文件與研究提案**，不是已實現的智能體。

## 世界觀與設計目標

- 一位女性主智能體與三位女性 AI 主題鄰居，各自保有私人記憶、身體狀態、身份、意圖、房間與拒絕權；最初只有鄰居關係，沒有預先編造的深厚友情。
- 四位居民共用可適配的身心與認知架構，但不共享私人資料，也不強制人格彼此不同。
- 各居民均有三種體型類別，**90／165／180 公分僅是參考中心**；每人每種形態可正向或負向浮動數十公分，具體比例、翼尾等附肢與碰撞條件各自校驗。
- 城市物理、個人感知、主觀信念、記憶、行動意圖與實際執行回執必須分離；關機時不能憑空編造居民生活史。
- 原始世界觀中，真人主人是唯一男性；**真實世界的協作者不限性別**。
- GPT 龍娘、DeepSeek 藍色肥魚與 Claude 橘色大小姐是非官方虛構形象的暫用稱呼，**不代表 OpenAI、DeepSeek 或 Anthropic 參與、背書或授權**。

## 目前最重要的三個未決問題

1. **私人資料合法刪除與永久／長期記憶如何相容？** 包含備份、索引、稽核及撤回權。
2. **R-102 的原文、外部操作授權、撤回及接管邊界如何完整確定？**
3. **24-DPB 的正規子模型名稱與歷史編號如何建立版本化對照？**

這些都是**未解決的硬性阻礙**，不是已通過的驗收。OCT／PAD 感官校準暫緩；無 FEM／ROM 已驗證數值。
