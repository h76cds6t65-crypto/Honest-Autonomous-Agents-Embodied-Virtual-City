# 自成之境

自主數位居民與具身世界研究計畫。研究從一個有因果與持久紀錄的模擬房間開始，逐步接續虛構元素場、身體與居民觀察。四位居民各有身份、記憶與拒絕權。工程指標只用於驗收。
